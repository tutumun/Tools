# ユニクロ MEN期間限定ページ すっきり表示

`UniqloMenCleanView.user.js` はTampermonkey用のユーザースクリプトです。

## 使い方

1. ブラウザーのTampermonkeyで「新規スクリプトを追加」を開く。
2. 初期コードをすべて削除し、`UniqloMenCleanView.user.js` の内容を貼り付けて保存する。
3. https://www.uniqlo.com/jp/ja/feature/limited-offers/men を再読み込みする。

商品カードのサイズ表記が `WOMEN, ...` の商品を、外枠ごと非表示にします。
「待望の特別価格」の見出しと商品カルーセルも、余白を含めて非表示にします。
スクリプト冒頭の `HIDE_SPECIAL_OFFERS` で切り替えられます。
`true` は非表示ON、`false` はOFF（通常表示）です。変更後は保存してページを再読み込みしてください。
「男女兼用」の商品も、WOMEN表記であれば非表示になります。
追加読み込みや並べ替え後も自動で判定します。
商品件数は、元の件数から非表示件数を引き、`51件 消した数(11件)` の形式で表示します。
非表示件数は読み込み済みの商品一覧から集計し、通常のスクロールで商品が追加されるたびに更新します。
全商品が読み込まれるまでは、未読み込みのWOMEN商品を差し引いていない暫定の件数です。

スクリプトはページ内遷移に対応するため日本向けサイト内で読み込まれますが、
非表示の処理が有効になるのは上記のMEN期間限定ページだけです。
解除するときはTampermonkeyでスクリプトを無効にしてページを再読み込みしてください。

商品カードのHTML構造が変更された場合は、セレクターの修正が必要になることがあります。

このスクリプトはAPIへの直接リクエスト、自動スクロール、全件自動読み込みを行いません。
サイトが通常の表示操作で読み込んだ商品を対象に、表示と件数を変更します。
API経由の全件取得は実装していません。APIの仕様変更による動作停止や、
過剰なリクエスト・無制限の再試行によるサイトへの負荷を避けるため、今後追加する場合も別途検討が必要です。
