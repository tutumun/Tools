# ユニクロ MEN期間限定ページ すっきり表示

## 簡単な説明

ユニクロのMEN期間限定価格ページで、WOMEN表記の商品と「待望の特別価格」枠を非表示にして、商品一覧を見やすくします。非表示にした商品数も表示します。

## 詳細

- WOMEN表記の商品カードを隠し、空いた場所に後続の商品を詰めます。
- 「待望の特別価格」の見出しと横並びの商品枠をまとめて隠し、下の商品一覧を上に詰めます。この機能は設定でON/OFFできます。
- 商品件数を `51件 消した数(11件)` のように表示します。元の62件から11件を非表示にした場合の例です。
- スクロールによる商品の追加読み込みや、並べ替え・絞り込み後も自動で処理します。

対象は[ユニクロのMEN期間限定価格ページ](https://www.uniqlo.com/jp/ja/feature/limited-offers/men)です。「男女兼用」の商品も、WOMEN表記であれば非表示になります。

### 件数について

非表示件数は、ページに読み込まれた商品から集計します。全商品が読み込まれるまでは、未読み込みのWOMEN商品を差し引いていない暫定の件数です。通常どおりスクロールすると、商品が追加されるたびに更新されます。

APIへの直接リクエスト、自動スクロール、全件自動読み込みは行いません。ユニクロ側のページ構造が変わると、非表示や件数更新が動作しなくなる場合があります。

## 使用方法

1. ブラウザーにTampermonkeyを導入します。
2. スクリプトの配布ページからインストールします。
3. [MEN期間限定価格ページ](https://www.uniqlo.com/jp/ja/feature/limited-offers/men)を開きます。すでに開いている場合は再読み込みしてください。

設定画面での操作は不要です。ページを開くと自動で非表示と件数更新が行われます。

### 「待望の特別価格」枠のON/OFF

Tampermonkeyのダッシュボードで、このスクリプトの編集画面を開き、冒頭の設定を変更します。

```js
// true：非表示ON（初期設定）／ false：OFF（通常表示）
const HIDE_SPECIAL_OFFERS = true;
```

枠を表示したい場合は `false` に変更し、保存してからユニクロのページを再読み込みしてください。

スクリプト全体の動作を止める場合は、Tampermonkeyで無効にしてページを再読み込みしてください。
